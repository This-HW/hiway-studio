# ADR-0004: 출력 프리셋 목록 조회 엔드포인트 추가

## 상태
승인 (HW가 2026-09-30에 승인)

## 배경
`POST /timelines/{id}/render`는 `export_preset_id`를 요구하지만,
프리셋 목록을 조회하는 엔드포인트가 시스템 설계서 §8.1에 없었다.
`export_presets` 테이블(§4.20)은 존재한다. P0 화면 설계(렌더 패널) 과정에서 발견됨.

## 결정
- `GET /export-presets` — 내장 프리셋 + 프로젝트 커스텀 프리셋 목록. query `?project_id=`.
- 타임라인 화면의 렌더 패널과 QC·출력 화면의 프리셋 선택이 이 엔드포인트를 사용한다.

## 근거
- ID를 요구하면서 목록 조회가 없으면 UI가 프리셋을 선택할 방법이 없다.

## 영향
- 코드: `routers/exports.py`에 1개 핸들러 추가 (Phase 3).
- 문서: 시스템 설계서 §8.1에 1행 추가됨.

## 관련
- 시스템 설계서 §4.20, §8.1 (`POST /timelines/{id}/render`), P0-18
