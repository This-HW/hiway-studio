# ADR-0010: Phase 6 (P2) 범위 — 4종 구현, 3종 제외/연기

## 상태
승인 (HW가 2026-09-30에 "다음작업 진행" 지시 — 범위 제안 포함)

## 배경
설계서 Phase 6는 "별도 계획"으로만 나열되어 있다 (3D 프리비즈, 월드 바이블,
QC 내용 검수, S3/CDN 확장, XML/EDL 출력, 클라우드 백업, 멀티 사용자·인증).
HW의 원칙(1인 로컬 퍼스트, "실제로 필요하거나 유용한 기능만")에 비추어
7종을 선별해야 한다.

## 결정
구현 (4종):
- XML/EDL 출력 — 타임라인 → FCP7 XML + CMX3600 EDL (Premiere·DaVinci 연동).
  외부 편집으로 넘기는 1인 창작자에게 실질적 가치가 있다.
- 월드 바이블 — 프로젝트별 서사 설정집 CRUD (인물·세력·장소·규칙·세계 연표).
- QC 내용 검수 — 스토리 충실도·연기 품질 체크 2종을 `CHECKS` 레지스트리에 추가.
  단, 내용 검수는 **조언(advisory) 등급**으로만 동작한다: `warn`까지만 내고
  `fail`을 내지 않는다. (판정에 vision 모델이 필요하고 stub만으로는
  출고 차단 근거가 약하기 때문. D-06의 P0/P2 역할 분리를 유지.)
- 3D 카메라 프리비즈 — 샷별 카메라 키프레임(위치·타깃·FOV) 데이터 모델 + API +
  웹 간이 3D 뷰어. 무거운 신규 의존성 없이 구현한다.

제외/연기 (3종):
- 멀티 사용자·인증 — **제외**. HW의 1인 원칙(팀·권한·멀티테넌트 제외)과 정면 충돌.
- S3/CDN 확장, 클라우드 스토리지 백업 — **연기**. 로컬 퍼스트 설계와 방향이
  다르고, ADR-0001 로컬 백업으로 당분간 충분. 필요해지면 별도 ADR로 재개.

## 근거
- 버린 대안: 7종 전부 구현 — 1인 로컬 사용자에게 S3/클라우드는 시기상조이고,
  멀티 사용자는 명시적 제외 항목이라 넣을 이유가 없다.

## 영향
- 코드: `routers/exports.py`(EDL/XML), `models/world_bible.py`+라우터,
  `services/qc_content.py`(CHECKS 2행), `models/camera_previz.py`+라우터·뷰어.
- 문서: MODULES.md 카드 추가, 설계서 §8.1에 P2 엔드포인트 행 추가.
- 호환성: 없음 (신규 테이블·신규 엔드포인트만).

## 관련
- 설계서 Phase 6 (1795행), D-06, ADR-0001
