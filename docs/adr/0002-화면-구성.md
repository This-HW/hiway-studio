# ADR-0002: P0 화면 구성 (워크스페이스 셸 탭·자막 탭 위치·설정 탭)

## 상태
승인 (HW가 2026-09-30에 승인)

## 배경
시스템 설계서 §2.2.1은 화면 목록을 나열하지만, 워크스페이스 셸의 탭 구성과 자막·스타일 키트 UI의 소속을 정하지 않았다.
`PROJECT_ARCHITECTURE.md` §5의 라우트에는 `subtitles/`가 독립 라우트로 있었으나, 9개 화면 단위로는 자막이 타임라인에 속한다.

## 결정
- 워크스페이스 셸 탭 8개: 스토리 / 캐릭터 / 보드 / 리뷰 / 타임라인 / QC·출력 / 비용 / 설정.
- 자막 편집 UI는 타임라인 화면 내 "자막" 탭으로 구현한다. 독립 탭·독립 화면을 두지 않는다.
  이유: 자막 큐의 시간축이 타임라인과 동일하고, 프리뷰·안전영역을 공유해야 한다.
- 스타일 키트·카테고리 팩(읽기 전용)·예산·기본 모델·화면비는 프로젝트 "설정" 탭에서 관리한다.
- 샷 단위 스타일 재정의는 보드·리뷰 화면의 샷 상세 패널에서 한다.

## 근거
- 자막을 독립 화면으로 두면 타임라인과의 시간 동기·안전영역 미리보기가 깨진다.
- 설정 성격의 것(예산·모델·화면비·키트)을 한 탭에 모아야 1인 운용 시 찾기 쉽다.

## 영향
- 코드: `apps/web/app/projects/[id]/` — `subtitles/` 독립 라우트를 만들지 않고 타임라인 내 탭으로 구현.
- 문서: `PROJECT_ARCHITECTURE.md` §5, `docs/MODULES.md`의 `apps/web` 라우트표, `docs/P0_SCREENS.md`에 반영됨.
