# ADR-0003: 업스케일·아웃페인트 엔드포인트 추가

## 상태
승인 (HW가 2026-09-30에 승인)

## 배경
F-07(수정·리테이크)은 `job_type='upscale'`·`outpaint`를 정의하지만, 시스템 설계서 §8.1에는
`POST /shots/{id}/inpaint`만 있고 업스케일·아웃페인트용 엔드포인트가 없었다.
P0 화면 설계(리뷰 화면) 과정에서 발견됨.

## 결정
- `POST /shots/{id}/upscale` — body `{generation_id, model_id?}` → `202 {job_id}`.
- `POST /shots/{id}/outpaint` — body `{generation_id, mask_path?, prompt, direction?}` → `202 {job_id}`.
- 새 잡 타입이므로 `frame` 엔드포인트에 합치지 않고 별도 엔드포인트로 둔다.
  (inpaint가 이미 별도인 것과 일관.)
- 비용은 이미지 모델의 `per_image` 단가를 그대로 사용한다 (설계서 §9.1 `[가정]`과 일치).

## 근거
- `frame`에 합치면 배치 생성과 단일 수정 작업의 의미가 섞인다. inpaint 선례를 따른다.

## 영향
- 코드: `routers/generations.py`에 2개 핸들러 추가 (Phase 2).
- 문서: 시스템 설계서 §8.1에 2행 추가됨. `docs/P0_SCREENS.md` §7 리뷰 화면에 버튼 반영됨.

## 관련
- 시스템 설계서 §4.11 (`job_type` enum), §5 F-07, `docs/P0_SCREENS.md` §7
